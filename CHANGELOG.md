# Changelog

## Unreleased - pre-publication repository release

- Added the SOLIAS specification, terminology, operational definitions, complete checklist, and worked examples.
- Added author, reviewer, short-form, and machine-readable templates.
- Added a standalone claim-evidence profile schema and a full prospective report schema in JSON Schema Draft 2020-12, with equivalent YAML serializations.
- Added validation of the permitted `(E, C, G)` combinations under `G = max(0, C - E)`.
- Added blank JSON and YAML templates whose required values remain unset until completion.
- Named blank JSON and YAML files explicitly as templates and added CSV author and short-form templates for spreadsheet-based use.
- Aligned the retrospective extraction schema with the same validated `(E, C, G)` representation used by the prospective schemas.
- Added the synthetic disaster-response report as a validated machine-readable example.
- Added a separate retrospective extraction schema for evidence synthesis.
- Added adoption guidance for authors, reviewers, venues, evidence synthesis, and domain profiles.
- Added governance and public issue-log templates aligned with the release plan in the paper.

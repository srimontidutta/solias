# Worked Examples

These examples are drawn from the illustrative material in the SOLIAS paper. The disaster-response example is a synthetic completed 20-item report. The public-services, healthcare, and accessibility examples show how a broader intended outcome can remain visible while the conclusion stays aligned with the demonstrated outcome. The boundary cases provide representative adjacent evidence-level assignments.

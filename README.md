# SOLIAS

**SOLIAS: A Reporting Standard for Social-Impact Claims in NLP**

SOLIAS (Social Outcomes for Language-Integrated AI Systems) is a reporting standard for relating social-impact claims in NLP to the outcomes directly evaluated in a study.

The framework includes six evidence levels, a claim–evidence alignment profile \((E, C, G)\), and a 20-item reporting checklist covering populations, contexts, mechanisms, evaluation, safeguards, maintenance, and claim scope.

## Release Materials

This repository will contain the materials accompanying the SOLIAS paper:

- Author reporting template
- Reviewer template and rubric
- Operational definitions for the six SOLIAS evidence levels
- SOLIAS checklist
- Worked examples
- Machine-readable schema

The release files are currently being finalized and will be added shortly.

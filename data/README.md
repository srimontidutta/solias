# SOLIAS Reference Tables

This directory contains compact tabular representations of material defined in the paper and specification:

- `evidence-levels.csv`: the six evidence levels, representative forms of direct evidence, and scope of supported conclusions;
- `boundary-cases.csv`: the adjacent-level cases used to illustrate evidence-level assignment; and
- `claim-evidence-profiles.csv`: all valid `(E, C, G)` combinations under `G = max(0, C - E)`.

The tables are intended for forms, documentation, spreadsheets, evidence-synthesis workflows, and compatible tools. This directory focuses on reusable reference material for applying SOLIAS; the retrospective audit remains documented in the paper.
